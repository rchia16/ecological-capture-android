## Implemented result

`server/ecocapture_gateway/` implements an HTTPS-only FastAPI/ASGI gateway with private SQLite development metadata, 256-bit installation tokens stored only as SHA-256 hashes, eligibility/policy/linkage allowlist and independent revocation. Synthetic local administration writes credentials exclusively outside the repository; production participant provisioning is unavailable.

The gateway accepts exactly the three immutable snapshot objects, enforces request/storage/disk/active-job/rate/concurrency/metadata bounds, resumes committed offsets after restart, rejects conflicting chunks and independently verifies object hashes, schemas and linkage. File writes are synced before offset commits; an uncommitted tail is recovered on the next write. Completion and a unique mock intent are committed together. The mock adapter contains no network client and produces an explicit mock, not-archived receipt. No FileSender credential was read and no FileSender or email call was made.

Raw access logs and exception content are suppressed, forwarded headers are trusted only from the loopback proxy by the launcher, HTTP is rejected and responses expose minimal health/error data. Filesystem paths use fixed names and canonical UUID job directories; symbolic links fail closed. Cleanup removes only checked staging paths, retains reservations on failed deletion, and never claims secure erasure or remote withdrawal. Completed mock data remains quota-counted until cancellation. Approved encryption at rest, backup/recovery, retention and monitoring remain operational decisions.

Review templates for nginx, systemd and host configuration are in `server/deployment/`; they are not activated or tested on an actual host.
